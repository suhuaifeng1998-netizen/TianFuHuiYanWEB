## 运行要求

上传完成确认需要浏览器提供 `window.crypto.subtle`。请使用本机预览/开发代理或 HTTPS；若普通远程 HTTP 页面显示“浏览器无法安全确认附件”，按访问方式排查。此要求来自当前线上源码，开发包保留同样行为。

预览使用固定虚构数据。原业务模块在服务器运行，不纳入 GitHub；本次未重新执行完整文献全文与三步研究分析验收。接入步骤见 [integration.md](integration.md)，修改步骤见 [handoff.md](handoff.md)。
