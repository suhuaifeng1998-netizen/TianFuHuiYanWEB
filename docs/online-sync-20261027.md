# 医学与机械臂线上源码同步

同步基线：2026-10-27 当前公开的医学问答与机械臂 Agent 页面。公开入口 HTML 和 JavaScript 与线上前端构建目录逐字节一致，且构建内容包含本次新增界面逻辑：医学 `index-BhT0DV51.js`，机械臂 `index-BCwOr38e.js`。

同步后逐项比对两套应用的 31 份 `src` 界面源码（含 CSS）；除下文列出的可配置地址适配外，内容与线上一致。

## 同步内容

- 医学：四川场景推荐及完整提问预填、历史会话可追问检查、过期记录重新提问、资料数量展示和对应样式。
- 机械臂：`RobotTwinView.tsx`、Three.js 0.180.0 依赖及锁文件、渲染姿态类型、浏览器相机操作、静态背景、暂停/继续和复位入口、当前手动控制与键盘方向映射。
- 门户补充：线上现有 banner 样式源码及摄像头/麦克风本地自检静态页。

目录映射：医学位于 `apps/portal/src/MedicalAgent.tsx`，机械臂位于 `apps/robot/src/`。完整页面继续使用现有线上 API。七个 STL 模型由服务公开资源接口提供，不复制服务端模型目录。

## 保留的开发适配

仓库保留 `apiUrl`、`websocketUrl`、公开入口环境变量、本地来源校验及开发代理。新 3D 模型加载也使用 `apiUrl`，并补充 `/robot-assets` 代理与来源检查；同步线上源码不会把接口固定到原生产主机。

保留两套应用的本地监听端口、公共资源准备脚本、安装/构建工具和空环境变量模板。线上专用 Vite 代理地址不复制到仓库。除这些可配置地址适配外，界面逻辑和 CSS 按线上源码同步，不借此重构或修改功能。

材料 Gradio 开发包继续保持同日已同步版本。后端路由、业务实现、真实环境文件、密钥、用户数据和服务配置均未纳入。

## 验证与交接

构建与接入步骤仍为根目录 `npm run setup`、`npm run connect:online -- --target http://221.239.50.147:7860`，再分别启动 `npm run dev` 和 `npm run dev:robot`。

运行 `npm run test:connection` 检查开发代理；`npm run check:connection -- --full` 检查真实医学 SSE/会话、材料队列/文件，以及机械臂 WebSocket、渲染姿态和模型资源。具体结果见 [验证记录](external-verification.md)。运动、使能、暂停/继续、复位等设备操作不作为本次源码同步的现场测试项目。
